# Standard Deviations

A tower defense game where you protect your base from waves of enemies by strategically placing towers. Defend against the incoming hordes and see how long you can survive!

## How to Play

- Survive as many waves of enemies as possible
- Place towers strategically to stop enemies before they reach your base
- Earn resources by defeating enemies to build more towers
- Each wave becomes progressively harder

## Controls

- **Click/Mouse**: Select towers, place them on valid build spots
- **Hover**: View tower range and upgrade options
- **UI Buttons**: Interact with tower selection and upgrade menus

## Towers

- **The Blind**: A basic tower with moderate damage and range. Great for early game defense.
- **The Legless**: A fast-firing tower that excels at taking down groups of weaker enemies.
- **The Deaf**: A high-damage tower with slower fire rate, perfect for taking down tougher enemies.

## Tech

Built with [kaboom.js](https://kaboomjs.com/), a JavaScript game development library.

## Running Locally

1. Clone the repository
2. Navigate to the `Game` directory
3. Open `index.html` in your browser, or serve with a local HTTP server

```bash
cd Game
python3 -m http.server 8000
# Then open http://localhost:8000 in your browser
```
